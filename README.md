# AI Red Teaming Notebook

My working notes and self-built test suites for AI red teaming.

I work on AI safety red teaming — probing models for harmful
outputs and writing up what I find. This repo is where I turn
that hands-on work into something structured: vulnerability
notes, test cases I design myself, and reports on what breaks.

## Contents

- `owasp-notes.md` — notes on the OWASP Top 10 for LLM Applications
- `log.md` — learning log

More to come as I build it out.
